# 政府采购招标 AI 系统 · 演示站

前端静态部署版本，**内置演示假数据，无需后端**，任意账号即可登录体验完整流程。

## 体验地址

https://yolo-livitup.github.io/tender-demo-preview/

## 演示流程

1. **登录**：任意用户名 + 密码即可（演示模式不校验）
2. **代理合同**：打开「DLHT-2026-009」可看到走完主流程的演示合同；也可「新建代理合同」走 模板检测 → 要素填写 流程
3. **采购需求与 AI 复核**：对「待复核」需求点「触发 AI 复核」，复核通过后自动生成采购文件草稿
4. **投标与开标**：页面为占位说明（真实业务由深圳公共资源交易平台承载）
5. **资格审查**：登记投标人 → 点「资格审查」，演示规则：公司名含「华信」「达能」判不合格
6. **符合性预检**：种子报价 468 / 300 / 441 / 未录入，覆盖 通过 / 异常低价警告 / 超限价 / 未录入 四种判定
7. **专家人工核对**：8 项清单逐家勾选，可下载资格性/符合性审查表（占位文件）
8. 数据保存在浏览器 localStorage，清空即恢复初始演示数据
